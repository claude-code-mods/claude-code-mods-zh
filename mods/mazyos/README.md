# MazyOS

> 中文版由 claude-code-mods-zh 项目翻译，原作者与许可证见文末。原版 README 见 [README.en.md](README.en.md)。

葡语商业操作系统插件：每次会话都带入你的公司记忆、输出带品牌视觉，并提供 17 个营销、SEO、Google Ads、Instagram 轮播与 Google Maps 客户开发技能。聊天旁有面板、提示行上方有状态条，并在破坏性 git 命令前设闸。

## 安装

```
/plugin install mazyos@claude-code-mods-zh
```
