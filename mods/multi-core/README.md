# multi-core

> 中文版由 claude-code-mods-zh 项目翻译，原作者与许可证见文末。原版 README 见 [README.en.md](README.en.md)。

在一个 Claude Code 会话中使用 ChatGPT (Codex)、Cursor、OpenCode Zen 与 Antigravity 模型。用 `/model` 切换，委派给命名的原生 worker，并保留每个提供方自己的登录与权限。

## 安装

```
/plugin install multi-core@claude-code-mods-zh
```
