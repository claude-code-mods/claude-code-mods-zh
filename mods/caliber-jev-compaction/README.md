# caliber-jev-compaction

> 中文版由 claude-code-mods-zh 项目翻译，原作者与许可证见文末。

为 Claude Code 会话提供逐字保留的 Jev 压缩。

## 安装

```
/plugin install caliber-jev-compaction@claude-code-mods-zh
```

安装后可在插件配置中填写自己的 TypeSafe API key。
