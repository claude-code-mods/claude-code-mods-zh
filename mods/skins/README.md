# Skins for Claude Code

> 中文版由 claude-code-mods-zh 项目翻译，原作者与许可证见文末。原版 README 见 [README.en.md](README.en.md)。

为 Claude Code 的转录提供皮肤：带图标的工具行、diff、表格和 Mermaid 图卡片、用量状态带，以及十五种主题。`/skin` 可实时切换。

## 安装

```
/plugin install skins@claude-code-mods-zh
```

安装后运行 `/skin` 选择主题。
