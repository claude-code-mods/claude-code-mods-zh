# claude-council

> 中文版由 claude-code-mods-zh 项目翻译，原作者与许可证见文末。原版 README 见 [README.en.md](README.en.md)。

同时咨询多个 AI agent（Gemini、OpenAI、Grok、Perplexity、Kimi、OpenRouter 路由的任意模型，以及已安装的 codex、antigravity、grok、kimi、cursor CLI 和本地 ollama 模型），以获得对编程问题的多元视角。提供 tmux 或 Claude Code 内的流式面板；开启后还会在你的提示行上方显示一行额外复查提示。

## 安装

```
/plugin marketplace add hex/claude-council
/plugin install claude-council@claude-council
```
